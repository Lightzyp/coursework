# CSCI 2910 — Server-side programming

Python data analysis, SQLAlchemy CRUD, API clients, Blazor library applications, a FastAPI social-media backend, a finance-bot prototype and a computer-vision prototype. These are historical coursework artifacts and prototypes; the archive does not claim every project is complete or currently buildable.

- Lab 6 also exists in the standalone [Lab-6 repository](https://github.com/Lightzyp/Lab-6).
- The ThreatCheck client reads `VIRUSTOTAL_API_KEY` from the environment. Supply your own key locally; none is included.
- Library seed readers are replaced with fictional example contacts.
- Local databases, environment files, build output and large external computer-vision model weights are omitted. Restore dependencies/model files for local use.
- ShinraNet retains Daniel's backend and authored report. The supplied course frontend is omitted. Initialize a fresh SQLite database from `Backend/schema.sql` before running it.
- Office reports are shared as cleaned text extracts.
