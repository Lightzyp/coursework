# CSCI 1200 - Adventures in Computing

Python labs and assignments by Daniel Macharia covering input/output, decisions, loops, functions, files, exception handling, inventory, and a grocery-budget tracker.

- `assignment-1-problem-solving`: completed Sudoku workbook.
- `assignment-3-decision-structure`: campus parking checker and pseudocode.
- `assignment-4-repetition`: event check-in program and case analysis.
- `lab-1-fundamentals`: student profile, restaurant calculator and meal discounts.
- `lab-2-inventory`: inventory program and documentation.
- `lab-3-lost-and-found`: menu-driven file storage, sample records and existing tests.
- `lab-4-grocery-budget`: grocery-budget script.
- `practice`: small classroom and pseudocode exercises.

Run a script with Python 3, for example `python CampusParking.py` from its assignment folder. Existing student implementations are preserved. Document text extracts omit screenshots and Office metadata.
