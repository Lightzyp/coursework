# CSCI 3500 — Security coursework

Completed reports covering Kali Linux, vulnerability analysis, Nessus, FERPA policy, physical security, firewall controls, private browsing and VeraCrypt, plus authored API documentation.

Reports are cleaned text extracts from Daniel Macharia's DOCX files. Embedded screenshots are omitted because they may contain private on-screen details. Office metadata and credential examples are removed. The original documents remain unchanged locally. A blank Lab 2 template is excluded. Lab descriptions concern classroom exercises and intentionally vulnerable local virtual machines.
